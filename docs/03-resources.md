# 第三章 · 精选学习资料库

> **选材原则：宁少勿多。** 资料收集本身会给人虚假的进步感。每个类别选 1–2 个用到底，比收藏 20 个更有效。下表中标 ⭐ 的是**建议主线**，其余为备选或特定阶段补充。

---

## 一、核心教材

### 主线教材（选一套，从头用到尾）

| 教材 | 出版社 | 适用 | 特点 | 建议 |
|---|---|---|---|---|
| ⭐ **Édito**（A1–B2） | Didier | 全阶段 | 目前法国 FLE 学校主流，语料新、文化内容强、直接对标 DELF 题型 | **首选**。2016 年后版本，A1/A2/B1/B2 四册配套完整 |
| **Cosmopolite**（A1–B2） | Hachette | 全阶段 | 任务型教学，交际情境设计出色，数字资源丰富 | Édito 的等价替代，二选一 |
| **Alter Ego +**（A1–B2） | Hachette | 全阶段 | 经典，结构清晰、体系严谨 | 老牌但语料略陈旧；若买二手/找配套资源多可选 |
| **Le Nouveau Taxi !** | Hachette | A1–B1 | 更轻量、进度快 | 适合时间紧或作为副线 |

> ⚠️ 主线教材必须配 **guide pédagogique（教师用书）或 cahier d'activités（练习册）+ 答案**，否则自学无法验证。

### 语法专项（贯穿全年，与主线并行）

| 书名 | 说明 |
|---|---|
| ⭐ **Grammaire Progressive du Français**（CLE International） | FLE 界最可靠的语法系列。左页讲解 + 右页练习，完全适合自学。按 Débutant → Intermédiaire → Avancé → Perfectionnement 分级 |

| **Easy French Step-by-Step**（Myrna Bell Rochester） | ⭐ **英文讲解**，按频率排序。对你极其友好——前 3 个月用它做"英语脚手架"能省大量时间 |

## 二、App 与在线工具

### 必装（核心工具链）

| App | 用途 | 费用 | 使用方式 |
|---|---|---|---|
| ⭐ **Anki** | 间隔重复记忆 | 免费（iOS 收费） | **全年最重要的工具**。见下方牌组配置建议 |
| ⭐ **italki** | 外教 1v1 口语课 | $8–30/小时 | 第 2 月起每周 1 次，第 5 月起 2 次。选 professional teacher 做纠错，community tutor 做闲聊 |
| ⭐ **Kwiziq French** | 自适应语法诊断与练习 | 订阅制 | 面向英语母语者设计，会精准定位你的语法漏洞并生成练习。对你**特别合适** |
| **Bescherelle Conjugaison** | 动词变位查询 | 免费/低价 | 随查随用 |
| **Le Conjugueur / WordReference** | 词典 + 变位 + 论坛 | 免费 | WordReference 的**英法**词典质量远高于中法词典，善用 |

### 强烈推荐

| App | 用途 | 说明 |
|---|---|---|
| **Clozemaster** | 语境填空刷词 | 碎片时间神器，比 Duolingo 效率高得多 |
| **Pimsleur French** | 纯音频听说课 | 通勤专用。对**发音和口腔肌肉记忆**效果突出，适合前 4 个月 |
| **Busuu** | 写作互批 | 你写法语交给母语者改，你帮别人改英语——写作纠错的免费来源 |
| **LingQ** | 分级阅读 + 生词管理 | 阶段③大量阅读时好用 |
| **Tandem / HelloTalk** | 语伴 | 免费口语/写作练习，但需要主动经营关系 |
| **Language Reactor** | Netflix/YouTube 双字幕插件 | 看剧学习必备（浏览器扩展） |

### 谨慎使用

| App | 问题 |
|---|---|
| **Duolingo** | 前 2 周当"热身玩具"可以，长期使用性价比极低，不足以支撑到 B2。**不要把它当主线** |
| **各类 AI 聊天工具** | 可做口语陪练和作文初筛，但**不能替代真人纠错**——AI 倾向于过度宽容，且会遗漏语域问题 |

### Anki 牌组配置建议（务必按此建卡）

```
字段设置：
  1. 法语（含冠词！ une voiture，不是 voiture）
  2. 例句（挖空形式，来自你真实读到/听到的语料）
  3. 中文/英文释义   ← 释义放背面，优先用英文（更精准，且强化英法链接）
  4. 音频（Anki 的 AwesomeTTS / HyperTTS 插件自动生成）
  5. 词性 / 阴阳性标记（可用颜色：阳性蓝、阴性红）

卡片类型：
  - 主卡：例句挖空 → 填词（不要做"中→法"孤立单词卡）
  - 副卡：听音 → 写词（训练音形对应）

每周新卡上限：100 张（阶段①可 150，阶段③④降至 70–80）
```

> **不要下载几千张的现成牌组。** 用你自己遇到的词建卡——记忆效果差 3 倍以上。现成牌组只推荐用于「高频词前 1000」的启动阶段。

|---|---|

| 播客 | 说明 |
|---|---|
| ⭐ **Le français facile avec RFI「Journal en français facile」** | **每日 10 分钟慢速新闻，附完整文字稿 + 练习**。免费，法国国际广播电台出品。**建议全年每天听**，是本计划的听力主干 |
| ⭐ **InnerFrench**（Hugo Cotton） | 中级学习者公认第一。清晰的准原速法语，谈文化/心理/社会，内容本身有价值 |
| **Français Authentique**（Johan Tekfak） | 清晰自然的法语，主题偏思维方式与日常表达 |
| **Little Talk in Slow French** | 慢速但自然的日常对话 |
| **News in Slow French** | 慢速新闻 + 语法讲解（付费部分质量高） |
| **One Thing In A French Day** | 每集 3–5 分钟法国日常生活，短小易坚持 |

## 五、阅读资源

### 分级阅读（按阶段）

| 阶段 | 资源 |
|---|---|
| **A1–A2** | ⭐ [Le français facile avec RFI](https://francaisfacile.rfi.fr/)（新闻稿 + 练习）；**1jour1actu**（法国儿童新闻，配视频）；Lawless French 的分级短文 |
| **A2–B1** | **Il était une histoire**（儿童故事）；分级读物系列 **Lectures CLE en français facile**、**Mondes en VF**（Didier）；LingQ 法语库 |
| **B1–B2** | **Le Monde**（付费墙外的免费文章 + Décodeurs）、**France Info**、**Courrier International**、**Slate.fr**、**Le Figaro**、**20 Minutes**（较易） |
| **B2** | ⭐ 报刊**社论 / tribune / éditorial** —— 这是 DELF B2 阅读与写作的直接对应文体 |

### 第一批原版书推荐（阶段③，第 6–8 月）

| 书 | 难度 | 说明 |
|---|---|---|
| **Le Petit Prince** | B1 | 经典入门，语言简洁但有深度 |
| **Le Petit Nicolas**（Sempé/Goscinny） | A2–B1 | 短篇、幽默、口语化，**最佳第一本** |
| **La Vie devant soi**（Romain Gary） | B1–B2 | 语言不难但风格独特 |
| **L'Étranger**（Camus） | B1–B2 | 句子极简（大量 passé composé），法国人最常推荐给学习者的原版书 |
| **Harry Potter à l'école des sorciers** | B1 | 若你熟悉英文版，可靠剧情推进阅读（善用你的英语背景） |
| **Kiffe kiffe demain**（Faïza Guène） | B1–B2 | 现代青少年口吻，当代法语 |

> 📖 **阅读方法**：阶段③开始，**泛读为主**（不查词，靠上下文推进，每天 20–30 分钟）+ **精读为辅**（每周 2 篇，逐句分析）。你的英语优势让你能比听力水平高一个级别去读——**要主动利用，读得比"你的级别"更难**。
