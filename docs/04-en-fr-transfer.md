# 第四章 · 英法双语迁移策略与「假朋友」防坑手册

> 你的英语 C2 是这份计划里最大的一笔资产。但它是一把**双刃剑**：在词汇和阅读上它送你半程，在发音和句法上它会持续地拖你后腿。本章的目标是——**把红利榨干，把干扰掐死。**

---

## 一、先建立正确的期待：英语优势到底作用在哪？

| 维度 | 英语的作用 | 净效果 |
|---|---|---|
| **词汇（学术/抽象）** | 1066 年诺曼征服后，大量法语词进入英语。现代英语中约三分之一的词汇源自法语 | 🟢🟢🟢 **巨大红利**，B1–B2 的抽象词汇近乎白送 |
| **阅读** | 词汇透明 + 拉丁语系句式熟悉 | 🟢🟢🟢 阅读可长期领先你的实际水平一个级别 |
| **语法概念** | 关系从句、条件句、被动、间接引语、时态呼应——概念全都已具备 | 🟢🟢 只需学**形式**，不需学**概念**，省一半时间 |
| **书面产出逻辑** | 议论文结构、论证方式与英语一致 | 🟢🟢 B2 写作的"骨架"你已经有了 |
| **日常核心词汇** | 法语最高频的词（rester, chercher, trouver, garder, encore…）恰恰**不是**英语借走的那批 | ⚪ 无帮助 |
| **发音 / 节奏** | 英语是重音计时，法语是音节计时；元音、r、鼻音全不同 | 🔴🔴 **强负迁移**，必须主动压制 |
| **介词 / 搭配** | 法语介词与英语常不对应 | 🔴 高频错点 |
| **阴阳性** | 英语无此范畴 | ⚪ 零帮助，只能硬记 |

### ⭐ 一个反直觉但很重要的发现

**在"节奏"这件事上，你的中文母语比英语更有用。**

- 英语是 **stress-timed（重音计时）**：单词有轻重音，非重读音节被压缩、元音弱化成 /ə/
- **法语是 syllable-timed（音节计时）**：每个音节时长大致相等，**单词层面没有重音**，重音只落在意群末尾
- **汉语普通话同样是音节计时**

结论：**读法语句子时，请调用你说中文的节奏感（每个音节饱满、等时），而不是说英语的节奏感。** 这一条能立刻让你的法语听感提升一大截，也是很多"英语很好但法语口音很重"的学习者从未被点破的问题。

## 二、词汇捷径：把英语词批量换算成法语词

### 2.1 后缀换算公式表（背下来，等于一次性获得数千词）

| 英语后缀 | → 法语后缀 | 性别 | 例子 |
|---|---|---|---|
| **-tion / -sion** | -tion / -sion | 阴 ♀ | information → **l'information**；decision → **la décision** |
| **-ty** | **-té** | 阴 ♀ | university → **l'université**；liberty → **la liberté**；quality → **la qualité** |
| **-ly**（副词） | **-ment** | — | rapidly → **rapidement**；normally → **normalement** |
| **-ous** | **-eux / -euse** | — | dangerous → **dangereux**；curious → **curieux** |
| **-ic / -ical** | **-ique** | — | economic → **économique**；logical → **logique** |
| **-ary** | **-aire** | — | necessary → **nécessaire**；ordinary → **ordinaire** |
| **-or / -er**（施事） | **-eur** | 阳 ♂ | actor → **l'acteur**；director → **le directeur** |
| **-ism / -ist** | **-isme / -iste** | 阳♂ / 通 | capitalism → **le capitalisme**；artist → **l'artiste** |
| **-ance / -ence** | -ance / -ence | 阴 ♀ | importance → **l'importance**；difference → **la différence** |
| **-able / -ible** | -able / -ible | — | possible → **possible**；acceptable → **acceptable** |
| **-ate**（动词） | **-er** | — | create → **créer**；participate → **participer**；communicate → **communiquer** |
| **-ize / -ise** | **-iser** | — | organize → **organiser**；realize → **réaliser** |
| **-ment** | -ment | 阳 ♂ | government → **le gouvernement**；movement → **le mouvement** |
| **-al** | **-el / -al** | — | natural → **naturel**；national → **national** |
| **-ive** | **-if / -ive** | — | active → **actif / active** |
| **-phy / -logy / -my** | **-phie / -logie / -mie** | 阴 ♀ | philosophy → **la philosophie**；biology → **la biologie** |
| **-sis** | **-se** | 阴 ♀ | analysis → **l'analyse**；crisis → **la crise** |

> 💡 **使用方式**：遇到不会说的抽象概念时，先用这张表把英语词"法化"，说出来。命中率约 70–80%。剩下 20% 会被外教纠正——那才是需要进 Anki 的词。

### 2.2 两条拼写侦探规则（阅读时极其好用）

#### 规则 A｜法语的长音符 `ˆ` ＝ 历史上丢失的 **s**

看到 `ˆ`，在它后面**补一个 s**，往往就是英语词：

| 法语 | 补 s 后 | 英语 |
|---|---|---|
| forêt | forest | forest（森林） |
| hôpital | hospital | hospital |
| île | isle | island |
| château | chasteau | castle |
| coût | coust | cost |
| bête | beste | beast |
| maître | maistre | master |
| tempête | tempeste | tempest |
| honnête | honeste | honest |
| goût | goust | gusto / gustatory |
| intérêt | interest | interest |
| conquête | conqueste | conquest |
| ancêtre | ancestre | ancestor |
| vêtement | vestement | vestment（衣物） |
| fête | feste | feast / festival |
| arrêter | arrester | arrest（停止/逮捕） |

#### 规则 B｜法语词首 `é-` ＝ 英语的 `s-` + 辅音

| 法语 | 英语 |
|---|---|
| étudiant | student |
| école | school |
| état | state |
| étrange | strange |
| épice | spice |
| éponge | sponge |

| épouse | spouse |
| écarlate | scarlet |

### 2.3 语域红利：拉丁词在英语里"高级"，在法语里"日常"

英语有 **日耳曼词 / 拉丁词** 的语域分层：`begin`（中性）vs `commence`（正式）、`ask`（中性）vs `demand`（强硬）、`help` vs `assist`。

**法语没有这个分层——那些在英语里显得文绉绉的拉丁词，在法语里就是普通日常词。**

| 英语（正式/罕见） | 法语（完全日常） |
|---|---|
| commence | **commencer**（就是"开始"） |
| terminate | **terminer**（就是"结束"） |
| assist | *（注意：assister à = 出席）* |
| comprehend | **comprendre**（就是"懂"） |
| respond | **répondre**（就是"回答"） |
| regard | **regarder**（就是"看"） |
| demand | **demander**（就是"问"，语气中性！） |
| profound | **profond**（就是"深"） |

**操作建议**：说法语时**不要因为"这个词在英语里太正式"而回避它**——大胆用拉丁词根，命中率很高。反过来，写法语时也别以为用了这些词就"高级"了，它们只是普通词，B2 作文要靠**结构和连接词**取胜，不是靠堆砌大词。

### 2.4 Anki 卡片预算法则（这条能省你几百小时）

**不要给"透明同源词"建卡。** `la nation`、`important`、`la situation`、`possible` —— 你已经会了，建卡是浪费。

把 Anki 的名额留给这四类：

| 优先级 | 类别 | 例子 |
|---|---|---|
| 🥇 | **假朋友**（见第五节） | actuellement, sensible, librairie |
| 🥈 | **高频却无英语同源的核心词** ← 这才是真正的难点 | rester, chercher, trouver, garder, laisser, encore, déjà, plutôt, quand même, d'ailleurs |
| 🥉 | **固定搭配与介词** | dépendre **de**, s'intéresser **à**, avoir envie **de** |
| 4️⃣ | **口语化表达 / 惯用语** | du coup, en fait, c'est-à-dire, n'importe quoi, ça marche |

> **关键洞察**：对英语母语者/高水平者来说，法语最难的不是学术词汇，而是**最日常的那 1000 个词**——它们大多来自古法语核心词汇，没被英语借走。你的英语优势在这里完全失效，必须靠死记和大量输入。

## 三、阴阳性：把英语没有的东西"系统化"

英语提供不了任何帮助，但**词尾规则**能覆盖 90% 的情况。

### 阴性 ♀ 词尾

| 词尾 | 例 | 可靠度 |
|---|---|---|
| **-tion / -sion / -ssion** | la nation, la décision | ~99% |
| **-té / -tié** | la liberté, l'amitié | ~99% |
| **-ance / -ence** | la chance, la science | ~95% |
| **-ure** | la culture, la nature | ~95% |
| **-ette** | la baguette | ~99% |
| **-ie** | la vie, la biologie | ~95% |
| **-esse / -ude / -ade** | la richesse, l'habitude, la salade | ~95% |
| **-eur**（抽象名词） | la peur, la couleur, la douleur | 需区分 |

### 阳性 ♂ 词尾

| 词尾 | 例 | 可靠度 |
|---|---|---|
| **-ment** | le gouvernement | ~99% |
| **-age** | le voyage, le fromage | ~90%（例外：la plage, l'image, la page, la cage, la nage, la rage） |
| **-eau** | le bureau, le château | ~95%（例外：l'eau ♀, la peau ♀） |
| **-isme** | le capitalisme | 100% |
| **-oir / -ier / -et / -on** | le miroir, le cahier, le paquet, le bâton | ~90% |
| **-eur**（施事者/机器） | le professeur, le moteur | — |
| **英语外来词** | le week-end, le parking, le smartphone, le shopping | ~95% |
| **语言/星期/月份/季节/树/金属/颜色/数字** | le français, le lundi, le vert | ~100% |

### 三条执行纪律
1. **Anki 卡片正面永远写 `un/une + 名词`**，绝不写裸名词
2. 用**颜色编码**（阳性蓝、阴性红）—— 视觉记忆对性别特别有效
3. 记不确定的词时，**造一个带形容词的短语**："une voiture blanch**e**" —— 配合的形容词会强化性别记忆

## 四、语法迁移：哪些能直接搬，哪些是新东西

### 4.1 可以直接搬运的（省时间）

| 语法点 | 英语对应 | 你只需学 |
|---|---|---|
| 关系从句 | who / which / that | 形式（qui/que/dont/où）而非概念 |
| 条件句三型 | if I have / if I had / if I had had | 形式对应（si + présent/imparfait/plus-que-parfait） |
| 被动语态 | be + p.p. | être + p.p. + **性数配合**（新增点） |
| 间接引语与时态呼应 | he said he was… | 规则几乎一致 |
| 比较级/最高级 | more…than / the most | plus…que / le plus |
| 复合时态的概念 | have done | avoir/**être** + p.p.（助动词二选一是新增点） |
| 议论文结构 | thesis-antithesis-synthesis | 直接复用 |

### 4.2 真正的新东西（必须投入时间）

| 难点 | 说明 | 应对 |
|---|---|---|
| **阴阳性 + 一致关系** | 形容词、过去分词、代词都要配合 | 从第一天就带冠词记词 |
| **动词变位的密度** | 法语每个时态 5–6 个不同形式，英语只有 1–2 个 | 每天变位练习 10 分钟，用 Bescherelle |
| **虚拟式 subjonctif** | 英语的虚拟式已退化，法语是活跃系统 | 阶段③重点；背"触发词清单"而非"规则" |
| **宾语代词的位置** | `Je le lui ai donné.`（动词前，且有固定顺序） | 语序表必须刻意练到自动化 |
| **两段式否定** | `ne … pas / jamais / plus / rien / personne` | 早期形成肌肉记忆 |
| **passé composé vs imparfait** | 英语无此对立（简单过去 vs 过去进行只是近似） | 阶段②的头号战役 |

### 4.3 ⚠️ 句法层面的"假朋友"——比词汇假朋友更致命

这些错误会在 DELF 写作里持续扣分：

| 英语习惯 | ❌ 错误法语 | ✅ 正确法语 | 说明 |
|---|---|---|---|
| I am eating | ~~Je suis mangeant~~ | **Je mange** | 法语**没有进行时**，用现在时 |
| I've lived here **for** 3 years | ~~J'ai habité ici pour 3 ans~~ | **J'habite ici depuis 3 ans** | "自…以来"用**现在时** + depuis |
| I **look at** the sky | ~~Je regarde **à** le ciel~~ | **Je regarde le ciel** | regarder / écouter / attendre / chercher / demander / payer **均为直接及物，不加介词** |
| I **enter** the room | ~~J'entre la pièce~~ | **J'entre dans la pièce** | 反过来，entrer 需要介词 |
| I like coffee | ~~J'aime café~~ | **J'aime le café** | 泛指必须加**定冠词** |
| I wash **my** hands | ~~Je lave mes mains~~ | **Je me lave les mains** | 身体部位用**定冠词 + 代动词** |
| It is important **to** work | ~~Il est important à travailler~~ | **Il est important de travailler** | 固定结构 `Il est + adj + de + inf.` |
| **Do** you speak French? | ~~Est-ce que tu fais parler…~~ | **Parles-tu français ? / Est-ce que tu parles…** | 法语无助动词 do |
| People **are** … | ~~Les gens est~~ | **Les gens sont** | gens 恒复数 |
| I think **about** it | ~~Je pense de ça~~（视语义） | **J'y pense**（想着）/ **Je pense à…** | 介词不可按英语推 |

#### 高频介词搭配（照抄英语必错）

| 法语 | 介词 | 英语 |
|---|---|---|
| dépendre | **de** | depend **on** |
| s'intéresser | **à** | be interested **in** |
| se souvenir | **de** | remember（无介词） |
| jouer | **à**（运动）/ **de**（乐器） | play |
| participer | **à** | participate **in** |
| répondre | **à** | answer（无介词） |
| téléphoner | **à** | phone（无介词） |
| obéir | **à** | obey（无介词） |
| ressembler | **à** | resemble（无介词） |
| réussir | **à** | succeed **in** |
| se moquer | **de** | make fun **of** |
| avoir besoin | **de** | need（无介词） |

### 4.4 书面规范差异（DELF 写作细节分）

| 项目 | 英语 | 法语 |
|---|---|---|
| 语言/民族/星期/月份 | English, Monday, **M**ay（大写） | **le français, lundi, mai**（小写！） |
| 标点前空格 | `Hello!` | `Bonjour !` `oui : non` `? ! ; :` **前加不间断空格** |
| 引号 | "quotes" | **« guillemets »**（内侧带空格） |
| 小数点 | 3.14 | **3,14**（逗号） |
| 千分位 | 1,000 | **1 000**（空格） |

| **occasion** | ≠ 仅 occasion | **机会 / 二手（d'occasion）** |
| **parent** | ≠ 仅 parents | **亲戚**（复数才常指父母） |
| **avertissement** | ≠ advertisement | **警告** ；ad = une publicité / pub |
| **commander** | ≠ command | **点单、订购** |
| **profiter de** | ≠ profit | **享受、利用** |
| **assurance** | ≠ 仅 assurance | **保险** |
| **important** | ≠ 仅 important | 也常表**"数量大的"**（une somme importante = 一大笔钱） |

### 5.4 使用建议

1. **把 5.1 的 20 个词做成 Anki 牌组，第 1 个月就学完** —— 这是投入产出比最高的 20 张卡
2. 建立**个人假朋友日志**：每次被外教纠正一个，就记一条（你自己踩的坑比任何清单都有用）
3. 写作检查清单里固定加一条：「本文中所有看起来像英语的词，都确认过词义了吗？」

## 六、把优势变成行动：8 条具体操作

| # | 操作 | 理由 |
|---|---|---|
| 1 | **所有语法解释都读英文版**（Lawless French、Kwiziq、Easy French Step-by-Step） | 英语的 FLE 资源生态远比中文丰富、术语更精准，且能直接建立英↔法映射 |
| 2 | **Anki 背面用英文释义，不用中文** | 英法之间是同一语系的直接映射，中文要绕一道弯，且常有语义偏移 |
| 3 | **查词用 WordReference（英法）而非中法词典** | 中法词典释义粗糙、例句少；WordReference 有论坛讨论细微差别 |
| 4 | **从 B1 起改用法法词典**（Le Robert / Larousse） | 这是从 B1 到 B2 的关键动作，能建立法语内部的语义网络 |
| 5 | **阅读刻意读"超纲"材料** | 你的阅读能力天然领先——不要用教材限制它。从阶段③就读真实报刊 |
| 6 | **Anki 只收非同源词、假朋友、搭配** | 别浪费名额在 `la nation` 上 |
| 7 | **发音练习时，主动切换到"中文节奏模式"** | 中文与法语同为音节计时，用中文的等时节奏读法语，比用英语节奏准得多 |
| 8 | **每次外教课要求老师专门标记"英语式错误"** | 让老师帮你识别你自己看不见的英语干扰（介词、语序、语域） |
