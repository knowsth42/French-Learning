## 二、每张卡上有什么

### 1. 发音 🔊

- **340 条法语音频**，由微软 Edge 神经语音合成，已打包进 `.apkg`，导入即可播放，**无需装任何插件**
- **词条用女声**（fr-FR-Denise，语速 −15% 便于听清）
- **例句用男声**（fr-FR-Henri，正常语速）
- 两个声音的区分不只是为了好看——按计划的思路，多一个音色就是多一点听力适应

### 2. 词性标签（按阴阳性着色）

每张卡背面顶部有一个胶囊标签，一眼看出词性：

| 标签 | 颜色 | 对应 |
|---|---|---|
| 名词 · 阳性 ♂ | 蓝 | `un / le` 开头的名词 |
| 名词 · 阴性 ♀ | 红 | `une / la` 开头的名词 |
| 动词 / 代动词 / 无人称动词 | 灰 | |
| 形容词 / 副词 / 连词 / 介词 | 灰 | |
| 固定短语 / 惯用表达 / 代词 | 灰 | |

词条本身也按阴阳性着色（`une veste` 显红，`le journal` 显蓝），标签和词条双重编码。

### 3. 语法细节块

背面有一个独立的「语法」框，内容按词性给：

| 词性 | 框里写什么 | 例 |
|---|---|---|
| **动词** | 变位组别 · **助动词** · 过去分词 · 关键变位形式 · 常带介词 | `rester`：第1组 -er · **助动词 être** · p.p. resté(e)(s) · je reste, nous restons |
| | 拼写变化会特别标出 | `jeter`：**je jette**, nous jetons（双写 tt）／`gérer`：**je gère**（é→è） |
| **名词** | 复数形式（不规则的加粗）· 相关词 | `un journal`：**复数 des journaux**（-al → -aux） |
| **形容词** | 阴性形式 · 复数 · 位置是否改变词义 | `doux`：**阴性 douce** ／ `propre`：**位置改变词义** |
| **副词/连词** | 语域（口语/书面）· 后接语式 · B2 用法提示 | `afin que` + **虚拟式**；`néanmoins`：书面语，**B2 议论文必备** |

### 4. 卡片类型

| 牌组 | 每条笔记生成的卡片 |
|---|---|
| 假朋友 01–03 | ① 识义（法→义）② **反查（英→法）** ③ **听音（音→词）** |
| 高频核心词 09 | ① 例句填空（主卡）② 认词（法→义）③ **听音写词** |
| 其余牌组 | 单卡 |

**反查卡**练的是输出方向——看到 `actually` 问你法语怎么说，并提示「不是 actuellement」。错误发生在输出方向，单向卡练不到。

**听音卡**利用新加的音频，直接对应计划里说的「dictée 训练音形对应」。

## 四、什么时候学哪个牌组

牌组编号就是**建议的启用顺序**。不要一次全部打开——按计划分批解锁：

| 时间 | 启用牌组 | 理由 |
|---|---|---|
| **第 1 月** | 01（一级假朋友）+ 06（后缀换算） | 计划里说的「投入产出比最高的 20 张卡」；后缀公式一学会就能立刻扩词 |
| **第 2 月** | 07（拼写侦探）+ 08（阴阳性词尾） | 配合 A1 词汇积累，越早建立性别直觉越省事 |
| **第 3–4 月** | 02（二级假朋友）+ 05（介词搭配） | 开始写作和口语课后，介词错误会集中爆发 |
| **第 5 月起** | 09（高频核心词） | 死亡谷阶段的主力牌组——这批词是你英语优势失效的地方 |
| **第 6 月起** | 03（三级假朋友）+ 04（句法假朋友） | 有了产出经验后，这些卡才有真实的纠错意义 |

### 建议的 Anki 设置

```
每日新卡上限：  第 1–2 月 15 张/天 · 第 3–8 月 10 张/天 · 第 9 月起 5 张/天
每日复习上限：  不设限（或 200）
新卡与复习顺序：复习优先
```

> ⚠️ 计划里的红线：**每周新卡不超过 100 张**。超了两个月后会复习雪崩。

### 觉得卡片太多？先关掉「听音卡」

519 张卡里有约 115 张是听音卡。如果一开始节奏太紧，可以：

**牌组齿轮 → 卡片类型 → 选中「听音…」→ 暂停（Suspend）**

等到第 3 个月听力起步后再解除暂停。**不建议永久关掉**——听音卡是本牌组里唯一直接练音形对应的部分。

## 五、自己加卡（重要）

**这 239 张只是启动包。** 计划里反复强调：真正有效的卡片是**你自己踩坑踩出来的**。

- 每周复盘时，把错误日志里**复犯 ≥2 次**的错误做成卡
- 外教纠正的每一个「英语式错误」，加进牌组 04 或 05
- 读到 / 听到的生词，用**原句**做例句挖空，加进牌组 09

### 加卡方式

编辑 [`data.py`](data.py)，然后重新生成：

```bash
pip install genanki edge-tts
python3 build_decks.py     # 自动为新词句合成发音
python3 preview.py         # 可选：生成外观预览
```

词汇条目的写法（例句里用 `**双星号**` 包住目标词，脚本自动生成挖空版和高亮版）：

```python
dict(fr="une voiture", pos="n.f.", gram="复数 des voitures · 车库 un garage",
     en="car", zh="汽车",
     ex="Je gare ma **voiture** ici.", exzh="我把车停这儿。"),
```

- `fr` 名词**务必带冠词** —— 脚本据此判断阴阳性并着色
- `pos` 见 `data.py` 顶部的词性代码表
- 音频**自动生成并缓存**在 `media/`，已有的不会重复请求网络

重新导入 `.apkg` 时 Anki 会**按笔记 GUID 更新已有卡片、只新增新卡**，你的学习进度不会丢失。

## 六、文件说明

| 文件 | 用途 |
|---|---|
| `data.py` | 所有卡片内容，**改这个文件** |
| `build_decks.py` | 生成脚本：笔记类型、卡片模板、CSS、牌组结构 |
| `tts.py` | 发音合成与缓存（edge-tts） |
| `preview.py` | 用真实模板渲染 HTML 预览，便于检查外观 |
| `media/*.mp3` | 340 条发音缓存，**随仓库提交**，重建时无需联网 |
| `dist/French-DELF-B2.apkg` | 导入 Anki 用 |
| `dist/csv/*.csv` | CSV 备份，每个牌组一个文件 |
| `dist/preview.html` / `preview.png` | 卡片外观预览 |

### 换发音语音

在 `tts.py` 顶部改：

```python
VOICE_WORD     = "fr-FR-DeniseNeural"   # 词条（女声）
VOICE_SENTENCE = "fr-FR-HenriNeural"    # 例句（男声）
```

其他可选：`fr-FR-EloiseNeural`、`fr-FR-RemyMultilingualNeural`、
魁北克口音 `fr-CA-SylvieNeural` / `fr-CA-AntoineNeural`。
换语音后删掉 `media/` 重新生成即可（`edge-tts --list-voices` 可看全部）。
